The Solo Shopify Seller Stack

Four inspected tools that cover store updates, payment questions, traffic numbers, and email campaigns — set up in under an hour, no coding required.

What's in this stack

  1. Shopify Admin MCP — official, lets your assistant check and update products/inventory/orders
  2. Stripe MCP — official, answers payment and payout questions (read-only)
  3. Google Analytics 4 MCP — official, plain-English traffic and conversion answers (read-only)
  4. Klaviyo MCP — official beta, drafts and sends email campaigns

Before you connect anything: two of these four tools (Shopify Admin and Klaviyo) can make real changes to your store or send real emails, not just look at data. Follow the confirmation-step instructions below for both — don't skip that part.

Step 1 — Set up your AI assistant

You'll need an MCP-compatible AI assistant already installed (this guide assumes you're using Claude — the desktop or web app). If you haven't set that up yet, do that first before continuing.

Step 2 — Connect Shopify Admin MCP

  1. In your assistant's settings, find "Connectors" or "MCP servers."
  2. Search for "Shopify" and select the official Shopify Admin connector.
  3. You'll be redirected to a Shopify login screen — sign in with your normal store admin account. This is the safe OAuth method; you are never asked to paste in a password directly into the assistant.
  4. On the permissions screen, review exactly what's being requested (products, inventory, orders) before approving.
  5. Turn on "confirm before changes" if the connector offers it — this makes the assistant ask you before it edits anything.

Step 3 — Connect Stripe MCP

  1. Same process: search "Stripe" in Connectors, select the official one.
  2. Sign in through Stripe's OAuth screen.
  3. Confirm the permission screen shows reporting/read access — not payout or refund control, which you don't need for this stack.

Step 4 — Connect Google Analytics 4 MCP

  1. Search "Google Analytics" in Connectors.
  2. Sign in with the Google account tied to your store's GA4 property.
  3. No further settings needed — this one is read-only by design.

Step 5 — Connect Klaviyo MCP

  1. Search "Klaviyo" in Connectors, select the official (beta) connector.
  2. Sign in through Klaviyo's OAuth screen.
  3. Turn on "confirm before send" in the connector's settings — this is the single most important toggle in this whole stack, since it stops the assistant from emailing your customer list without your review.

Step 6 — Test it safely

Before relying on the stack for real work, try low-stakes questions first:

  • "What were my top 3 products by revenue last week?" (tests GA4 + Shopify, read-only)
  • "Do I have any failed payments in the last 7 days?" (tests Stripe, read-only)
  • "Draft — don't send — an email about our new arrivals." (tests Klaviyo without risk)

Only once you're comfortable with how it responds should you approve a real write action (updating a product, sending a campaign).

This stack was tested end-to-end before publishing. If any of these tools change their setup flow, tell us and we'll update this guide.
